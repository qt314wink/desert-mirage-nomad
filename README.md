# 🏜️ Desert Mirage Nomad

> *A generative visual journey through dune, fracture, and oasis bloom.*

Interactive single-page canvas experience with terracotta dunes, copper kintsugi cracks, Berber geometric overlays, and click-to-bloom botanical animations. Mouse movement and scrolling drive the narrative from drought to repair to bloom.

## What It Does

- **Dune Engine** — 5-layer animated sine-wave dunes with heat shimmer overlay in terracotta and ochre
- **Berber Pattern** — Scrolling geometric tile overlay (diamonds, circles, crosses) in soft-light blend mode
- **Kintsugi SVG** — Procedurally branching copper crack paths via SVG with `linearGradient` fill
- **Particle Sand** — 280 wind-drifting sand particles in desert palette with phase-based animation
- **Click-to-Bloom Plants** — Leaf sprout animation with Web Audio wind tone synthesis on click
- **GSAP ScrollTrigger** — Chapter narrative sections revealing on scroll with parallax hero
